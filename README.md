## Бизнес-правило варианта 7

Оценка за поведение не может быть выше `4`, если у ученика больше `3` пропусков без уважительной причины.

Реализация:

1. При добавлении записи о поведении с флагом `is_unexcused_absence=true`
   система считает прогулы без причины.
2. Если прогулов становится больше 3, а оценка за поведение выше 4,
   оценка автоматически снижается до 4.
3. Если явно пытаться поставить оценку 5 через PUT `/api/students/{id}`,
   API возвращает `400 Bad Request`.
